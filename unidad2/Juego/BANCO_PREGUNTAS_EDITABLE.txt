BANCO DE PREGUNTAS — GUÍA DE EDICIÓN
======================================

Archivo:
  js/banco_preguntas.js

Puede editar terminología, redacción, opciones y retroalimentación SIN tocar
el motor del juego.

Ejemplo:

{
  id:"U2_MRU_001",
  type:"mcq",
  difficulty:1,
  prompt:"En un MRU ideal, ¿qué magnitud permanece constante?",
  options:["la velocidad","la posición","...","..."],
  answer:"A",
  explanation:"En MRU la velocidad es constante..."
}

Respuesta correcta:
  "A", "B", "C" o "D"
También se aceptan 0, 1, 2 o 3.

MATEMÁTICA
==========
Para futuras ediciones se recomienda:

  "$v=\\Delta x/\\Delta t$"

Ejemplo:
  prompt:"Si $v=3\\,m/s$, ¿qué distancia recorre en $4\\,s$?"

TIPOS
=====
mcq         -> selección múltiple
graph_mcq   -> selección múltiple con gráfica
simulation  -> desafío con sliders

IMPORTANTE
==========
No cambie el id de una pregunta ya utilizada si desea comparar estadísticas
entre distintas versiones. Para una pregunta nueva, cree un id nuevo.


V0.3 — ORDEN ALEATORIO DE OPCIONES
===================================
Las opciones de cada multiple choice se mezclan automáticamente cada vez
que se muestra una pregunta.

Por lo tanto, el alumno no puede memorizar que "la respuesta es la B".

IMPORTANTE AL EDITAR
====================
El campo:

  answer:"A"

se refiere al ORDEN ORIGINAL escrito en este archivo, no a la letra que
aparecerá visualmente en una partida.

Ejemplo:

  options:[
    "velocidad",      <- A en el archivo
    "posición",       <- B
    "aceleración",    <- C
    "tiempo"          <- D
  ],
  answer:"A"

El juego puede mostrar visualmente:

  A) tiempo
  B) velocidad
  C) posición
  D) aceleración

y seguirá reconociendo correctamente "velocidad" como respuesta válida.

Para la analítica futura se registran:
- índice original elegido;
- posición visual mostrada;
- letra visual seleccionada;
- índice original de la respuesta correcta.

V0.5 — DIFICULTAD Y PUNTAJE
============================
Cada actividad posee:

  difficulty: 1
  difficulty: 2
  difficulty: 3

El motor transforma automáticamente esa dificultad en puntaje:

  Nivel 1 = 100 puntos
  Nivel 2 = 150 puntos
  Nivel 3 = 200 puntos

Esto permite modificar posteriormente la dificultad de una pregunta sin
tener que escribir manualmente su puntaje.

La energía es independiente:
  correcta   +0.5
  incorrecta -1.0

Por lo tanto pueden analizarse por separado:
- precisión;
- dificultad;
- puntaje ponderado;
- tiempo de respuesta;
- energía;
- número de intentos en simulaciones.

CANTIDAD V0.5
=============
Hay 23 casillas y 5 actividades por casilla:

  23 × 5 = 115 actividades.

La selección dentro de cada casilla continúa siendo aleatoria.

V0.7 — EDITOR LOCAL
===================
Ya no es necesario editar este archivo JavaScript manualmente.

Abrir:
  editor_banco.html

El editor permite modificar visualmente:
- enunciados;
- opciones;
- respuesta correcta;
- dificultad;
- explicación;
- tipo de pregunta;
- simulador asociado;
- objeto graph en modo avanzado.

Después debe exportarse el archivo:
  banco_preguntas.js

y reemplazar:
  js/banco_preguntas.js

IMPORTANTE
==========
El desafío "Comprar energía" toma preguntas de dificultad 3 de cualquier
tema. Para que una pregunta pueda aparecer allí debe cumplir:

  difficulty: 3

y ser:
  type: "mcq"
o:
  type: "graph_mcq"

Las simulaciones nivel 3 siguen disponibles en el recorrido normal, pero no
se utilizan para comprar energía, para que la recuperación sea rápida.
