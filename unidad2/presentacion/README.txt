UNIDAD 2 · CINEMÁTICA · PRESENTACIÓN BASE V0.3

Abrir index.html en Microsoft Edge o Chrome.

Cambios principales de V0.3:
- Los ejemplos del punto 18 incorporan el enunciado completo del problema según el apunte de la Unidad 2.
- La diapositiva 7.1–7.3 organiza rapidez media, velocidad media y velocidad instantánea en una única secuencia vertical e identifica qué expresa cada ecuación.
- La diapositiva 9. Gráficas del MRU incluye gráficas específicas x(t), v(t) y a(t).
- Todas las ecuaciones de la presentación poseen ahora una identificación visible y una breve interpretación física o de uso.
- Se mantiene la voz del sistema mediante Web Speech API.
- Se mantiene MathJax local y el contenido multimedia original.

Controles:
- Flechas izquierda/derecha: diapositiva anterior/siguiente.
- Botón índice: menú de diapositivas.
- Botón guion: abre el guion oral.
- Botón Leer: reproduce el guion usando una voz del sistema.
- Pausa / Detener: control de síntesis de voz.
- F: pantalla completa.
- Doble clic en infografías: ampliación.
