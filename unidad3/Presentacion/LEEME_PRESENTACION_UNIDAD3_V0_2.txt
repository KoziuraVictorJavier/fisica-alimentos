UNIDAD 3 · PRESENTACIÓN HTML · V0.2
====================================

Revisión solicitada respecto del modelo de la Unidad 2.

1. FÓRMULAS / MATHJAX
- Se corrigió la configuración de delimitadores LaTeX del archivo HTML.
- Delimitadores utilizados: \\( ... \\) y \\[ ... \\].
- Se revisaron las expresiones matemáticas y se normalizó la tipografía de unidades y subíndices descriptivos.

2. GUIONES
- Los 57 guiones se encuentran en guiones.js.
- El botón GUION permite ver el texto de la diapositiva actual.
- El botón LEER utiliza ese mismo texto, no el contenido visual bruto ni el código LaTeX.

3. LECTURA
- Preferencia: voz es-AR, luego es-UY y luego cualquier voz española disponible.
- Controles: Leer, Pausa/Reanudar, Detener y Auto: OFF/ON.
- Con Auto: ON, al finalizar la lectura se avanza y se lee la diapositiva siguiente.

4. CONTROLES
- Índice
- Anterior / Siguiente
- Guion
- Leer
- Pausa / Reanudar
- Detener
- Auto: OFF / ON
- Pantalla completa
- Apunte U3 como botón independiente abajo a la derecha

5. ATAJOS
- Flecha derecha / PageDown: siguiente
- Flecha izquierda / PageUp: anterior
- M: índice
- G: guion
- R: leer / detener
- Espacio: pausa / reanudar durante la lectura
- F: pantalla completa
- Esc: cerrar paneles y detener lectura

La carpeta conserva MathJax local, logos, SVG, infografías y demás assets para uso offline/GitHub Pages.
