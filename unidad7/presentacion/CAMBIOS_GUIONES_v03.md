# Revisión v0.3 — guiones de infografías

Se ampliaron y fundamentaron los guiones de las cinco infografías: historia, concepto de campo, carga y electrización, conductores y electroscopio, y distribuciones esféricas. Se actualizaron tanto el contenido incrustado en index.html como el archivo guiones_presentacion.json. No se alteraron las simulaciones ni las 36 filminas.

Nota: si el navegador conserva guiones personalizados, usar **Restablecer** en la filmina para escuchar la nueva narración predeterminada.
